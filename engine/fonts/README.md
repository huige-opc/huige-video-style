# Fonts

These font files ship with the engine. All are free under the SIL Open Font License 1.1 (license texts in `licenses/`):

| File | Family | Used by |
|---|---|---|
| `Anton-Regular.ttf` | Anton | the condensed display type across most templates |
| `ArchivoBlack-Regular.ttf` | Archivo Black | fallback display type |
| `PlayfairDisplay.ttf`, `PlayfairDisplay-Italic.ttf` | Playfair Display (variable) | T21 Clean & Minimal |
| `SpaceMono-Regular.ttf`, `SpaceMono-Bold.ttf` | Space Mono | T20 Fast-Paced Social Media |

Also install these system-wide:

- **Smiley Sans Oblique** (得意黑 — burned CN + EN captions)
- **Inter** — https://rsms.me/inter/ (stage)
- **Noto Sans CJK SC** (Black weight, on-screen Chinese)
- **Noto Color Emoji**
